This directory contains the unmodified FFmpeg executable and shared libraries
selected by provenance.json. LICENSE.txt contains the supplied LGPL v3 license.
licenses/COPYING.LGPLv3 and licenses/COPYING.GPLv3 together contain the LGPL v3
terms and incorporated GPL v3 terms. licenses/LICENSE.md is FFmpeg's upstream
licensing overview; its referenced version 2 license texts are also retained.
build-configuration.txt records the executable's version and build configuration.
Only optional synthetic-fixture regeneration uses this encoder. Normal builds,
tests and game releases use the separate, locally built native audio decoder.

This software is based in part on the work of the Independent JPEG Group.
Digi-Tactics makes no changes to FFmpeg's libavcodec/jfdctfst.c,
libavcodec/jfdctint_template.c or libavcodec/jrevdct.c. Their upstream copyright
and no-warranty notices are preserved in the pinned FFmpeg source archive.
