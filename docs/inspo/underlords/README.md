# Dota Underlords reference

Reference data on Dota Underlords (Valve, June 2019 to November 2020), kept as design inspiration for Digi-Tactics. Compiled 2026-10-15 from game data files, Valve patch notes and the community wiki. Sources and conventions are listed at the top of `underlords.md`.

| File | Contents |
|---|---|
| `underlords.md` | Overview: timeline, economy and rules, modes, ranked, battle passes, Underlords, alliances, final roster, gaps |
| `underlords.json` | Everything in one machine-readable file |
| `underlords-heroes.md` | All 85 heroes: stats at six snapshots, abilities, 3-star and Ace effects, change logs |
| `underlords-items.md` | Item mechanics, item pools per snapshot, every item on the wiki |
| `underlords-beta-season.md` | Beta season (2019-06 to 2020-02): Hype, talents, Jail, global items, Aces, loot rounds |
| `underlords-season-1.md` | Season One (2020-02 to 2020-11): City Crawl, Battle Pass, Hats, 3-star effects, August 2020 rotation |

Snapshots used for stats: 2019-06-20, 2019-10-10, 2019-10-24, 2019-12-06, 2020-02-25, 2020-11-19.
