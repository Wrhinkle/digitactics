## Set mechanics and system changes

- Hacks: rule-bending events that always favor the player. Two to five Hacks per game. They change augments (extra augment round, augment rounds moved earlier, category-locked augments), shops (two-star units in shop, lucky trait shops), carousels, loot orbs and opening encounters. Riot described Hacks as an evolution of Set 11 Encounters with more player agency.
- Exotech gives unique items only Exotech champions can equip; Cypher gains Intel from lost combats (more on loss streaks) and trades Intel for loot on set rounds; Divinicorp champions each grant a different team stat; Street Demon paints hexes that buff allies standing on them. See traits.
- Set-specific items in data include Exotech gear, trait "Mods", and Hack armory options (egg hatching, golem picks, gold split votes).
