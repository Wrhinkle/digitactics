## Set mechanics

- Elemental Hexes: each game picks one element (Inferno, Ocean, Cloud, Mountain). Every board has hexes of that element; a unit on the hex gets a bonus. The matching elemental drake replaced the standard dragon PvE. [9.22 notes, CDragon hex items]
- Qiyana's element changes each game to match the game's element. [wiki]
- Lux (cost 7 in data) has 10 element variants; each game has a pool of 10 Luxes with set elements; buying a second Lux replaces the first one's element. [wiki]
- Avatar trait: the Avatar's origin counts twice; owning one changes other Avatars in your shop to its element. Precursor to Set 4 Chosen. [CDragon, wiki Chosen]
- Board size increased from 3x7 to 4x7 hexes per side. [9.22 notes]

## Economy and system changes

- Champion pool per champion: tier 1 = 29, tier 2 = 22, tier 3 = 16, tier 4 = 12, tier 5 = 10. [9.22 notes]
- Player damage per stage: 2/3/4/5/6/7. Summoned units do not deal player damage. [9.22 notes]
- Level 8 odds: 15/20/35/24/6%. [9.22 notes]
- Mana per attack: 8 (1-star), 10 (2-star), 12 (3-star). Mana from damage taken reduced by 15%. [9.22 notes]
- Spatula items no longer give double stats. Cursed Blade removed. Spatula drop rate reduced. [9.22 notes]
- Dragons drop two common orbs plus their item; Elder Dragon and Rift Herald drop a common and an uncommon orb. [9.22 notes]
