## Set mechanics and system changes

- Charms: a Charm takes the place of one unit in the shop. Buying it gives a one-time effect (extra loot, a combat buff for the next fight, a free unit, rerolls, recombobulating a unit and so on). Charms start in Stage 2, appear about every third shop, and only one can be bought per round. Later Charms are stronger and cost more gold. 144 Charm rows below with tier and cost.
- Arcana: an Arcana signifier item chooses a High Arcana champion, and each Arcana scales from a different condition (3-star units, equipped items, active traits, Charms bought). Portal: objects fly out of a portal during combat to help allies and hinder enemies. Chrono: a countdown that speeds up with Chrono casts and ends in a special effect. Sugarcraft: sugar from components held after player combat builds cake layers; at 7 layers the player gets treats. See traits.
- Set 12 is the source of the Charm system that Set 18 reuses as Wisps.
