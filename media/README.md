# Digi-Tactics media kit

- `digi-tactics-trailer.mp4`: 25-second, 1920×1080, 30 fps H.264/AAC gameplay trailer, with “Tamer's Morning WIP” by mikl_pls, in-engine camera choreography, DigiFarm feeding and praise, and short animated titles.
- `digi-tactics-trailer.srt`: caption sidecar.
- `github-social-preview.jpg`: 1280×640 repository/social preview, under 1 MB.
- `github-cover.png`: full-resolution cover master.
- `tweet-draft.txt`: teaser copy; not posted.

The trailer is recorded from the running game using staged local showcase boards. The combat engine, UI, final-hit cinematic and dance are real. Frames are captured with hardware rendering at fixed 1/30-second simulation intervals, so recording overhead cannot drop animation frames. This is an offline gameplay capture, not a real-time performance benchmark. The footage does not demonstrate a live multiplayer lobby, public service availability or population. Cinematic shots use the existing renderer's orbit camera and hide the HUD for capture; the game itself is unchanged. Editing adds focused UI zooms, cursor emphasis, transparent animated titles, cuts, and sound. Capture/edit recipes are `tools/capture-trailer-cinematic.cjs` and `tools/render-trailer-cinematic.py`; earlier rough-cut recipes remain alongside them. Source capture and intermediate render evidence remain in the private local launch work directory rather than the distributable source.

Trailer music: **“Tamer's Morning WIP” — mikl_pls**, supplied by William as `mikl_pls - digi-tactics - Tamer's Morning WIP 2026-10-16 1335.wav`. The edit uses the supplied recording with a short closing fade, plus quiet original synthesized purchase ticks, an evolution chime and transition swishes. The mix is normalized to -16 LUFS with a -1.5 dBTP ceiling. The source WAV is not bundled with the game.

The trailer ends with “GET ON GITHUB NOW”. Detailed credits remain in this repository rather than an end-credit card. The public project is https://github.com/Wrhinkle/digitactics.

The current cut opens on Agumon at character height, follows a Normal-pace solo match through real purchases and a three-copy Agumon-to-Greymon evolution, then continues the same fight from an orbiting camera. One Double Up battle follows: its HUD establishes the partner/team format before a wider camera sweep shows both teams. The final-hit cinematic and ground-aligned dance lead into the corrected cover and GitHub ending. No gameplay shot is repeated. The shop, gold counter and bench remain visible while buying.

Production follows the **Super Video Maker** skill's story-first planning, distinct visual jobs, purposeful camera motion, transparent typography, audio finishing and visual QC. The [shot plan](trailer-storyboard.json) records the copy spine and each shot's purpose. The product-demo recipe is adapted to a music-led game trailer using actual game pixels and cameras, rather than a laptop mockup or presenter.

The cover was generated with the built-in image-generation tool, with the approved Chaos portrait as a character/style reference. The social preview is a resized JPEG export. It is AI-assisted fan artwork, not official key art. Original character/model credits and unresolved rights information are in [CREDITS.md](../CREDITS.md). Do not describe the assets as licensed for unrestricted redistribution.
